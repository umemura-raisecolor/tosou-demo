iroha studio ホームページ（HTML/CSS/JavaScript）

【プレビュー方法】
1. ZIPを解凍します。
2. index.html をブラウザで開きます。

【ファイル構成】
- index.html : ページ構成・文章
- style.css  : 配色、レイアウト、レスポンシブ対応
- script.js  : スマホメニュー、スクロール表示、年号
- assets/    : 共有画像を使ったページ素材

【公開前に必ず変更する箇所】
- iroha studio：実際の会社名・屋号に変更
- hello@example.com：実際に受信できる問い合わせ先に変更
- 料金、返信目安、サービス内容：実際の提供条件に合わせて変更
- 制作実績：掲載許可のある実績画像・実績情報に差し替え
- Google Fontsはインターネット接続時に読み込まれます

※掲載用の文章・料金・実績名はサンプルです。実際のサービス内容に合わせて調整してください。
